Solmar is an original 3D open-world crime game set in a sun-soaked coastal city: explore on foot or by car, weave through traffic and pedestrians, steal cars, outrun the police as your wanted level climbs, fight through 4 story missions, and track it all on a HUD with a minimap, health, money and objectives — with save/load so a run can be picked up later. Everything here is original; nothing is taken from Rockstar.

## Run it

```sh
node serve.ts  # then open http://localhost:8080
```
