Solmar is an original 3D open-world crime game set in a sun-soaked coastal city: explore on foot or by car, steal cars, outrun the police, fight through 8 story missions. Riko Vane runs jobs for Mara Solano while the Solmar PD — and its CONDOR-1 helicopter — try to bring him in.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No network needed: the game is static files under game/.
